### 平台缺陷（重要，长期有效）

以点开头的隐藏文件（`.dockerignore` / `.env` / `.gitignore`）上传到资料库后，元数据 `name` 字段为空（只有 `ext` 有值），导致：

- `file_delete` → `smhheal: empty name in chain`
- `file_rename` → 同样报 `resolve path: empty name in chain`
- `file_move` → 报「无法识别文件类型，请显式传入 type 参数」，但工具 schema 为 `additionalProperties: false`，无法传 `type`，此路堵死

结论：这类文件会变成**删不掉的僵尸文件**，只能走平台侧工单处理。后续避免把点开头文件传进资料库。
