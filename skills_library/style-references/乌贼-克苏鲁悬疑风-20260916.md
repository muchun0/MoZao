# 爱潜水的乌贼风格（《诡秘之主》）

## 核心气质
"纪律"二字。用精确文字搭建世界观，用克制笔触营造诡谲氛围，不靠华丽辞藻靠细节逻辑。

## 叙事手法

### 1. 冷感叙事，展示而非讲述
- 把叙事引擎从"解释"换成"发生"
- 情绪钉在可观测的客观事实上，砍掉偷懒的内心独白
- 让读者自己悟情绪，留填空区

### 2. 动词驱动动作链
- 抽象情绪全部拆解成有因果的动作链
- 每个微动作都在往前拱情节
- 不说"气氛僵了"，写具体动作（手指停止转动/目光偏移）

### 3. 悬疑解谜节奏
- 剧情层层递进，伏笔遍布全文
- 前期细小线索后期一一呼应
- 每个谜团解开同时推动故事前进
- 拒绝无脑开挂横推，靠智斗和布局

### 4. 多视角群像
- 非主角POV占37%
- 主线+副线并进，配角有独立成长弧
- 每个身份都有完整人设，经历交叉成网状

## 语言特征

- **通感描写**："煤烟味带着铁锈的腥甜""寂静有重量，压得耳膜嗡"
- **修辞系统统一**：用蒸汽机械术语喻命运（齿轮咬合）、天文意象喻失控（星轨偏移）、病理学术语喻堕落（灵性坏死）
- **短句为主**，不堆砌长句
- **环境带情绪**，但不直接说情绪

## 适用题材
克苏鲁/悬疑/蒸汽朋克/西幻/智斗流。不适合无脑爽文。
