# 副本结构三段式与锁链嵌套

每个叙事单元（副本）按「起因→经过→结果」搭建。

## 一、单副本三段式

### 1. 起因段：铺垫期待
- 提前抛出事件诱因，拉读者期待
- 不单独成段，嵌入上一个副本结尾
- 做到"上事未毕，下事已起"

### 2. 经过段：剧情展开
- **梦境/感官副本**：第一视角感官体验为主，写异质感（和人类不同的感知/时间流速/死亡体验），前缓后紧
- **现实/信息副本**：人物互动和信息差为主，用信息差制造张力
- 用连续小起伏替代单个大高潮，每个副本内设2-3个小反转

### 3. 结果段：收获成长+钩子
每个副本结束主角必须有实在收获：
1. 感官残留（新的身体异常/感知能力）
2. 线索碎片（手稿/遗物/关键台词）
3. 认知升级（对世界/自身的新理解）
4. 关系变化（和其他角色的关系推进或裂痕）

收获本身就是下一个副本的起因。

## 二、倒推设计法

1. **先定结局**：这个副本的最终记忆点是什么？
2. **反向拆节点**：从结局往回推3-5个关键节点
3. **控制大纲颗粒度**：只定结局锚点+关键节点，中间细节开放

## 三、锁链式嵌套

**基础模式：** A副本中段埋B伏笔 → A副本结尾 → B副本启动

**多层伏笔：**
- **长线**：跨多个副本慢慢放，最后集中回收
- **中线**：穿插在2-3个副本里逐步揭露
- **短线**：每章末尾留一个小悬念

**节奏公式：** 大副本+小日常副本交替，避免持续高压。

## 四、AI创作配套

1. 每个副本生成前分两部分提示词：固定基底（人设/世界观/调性）+ 动态副本模块（核心落点/节点/感官侧重）
2. 每个副本换主导感官/视角，避免写法重复
3. 不同副本调温度：梦境场景0.7-0.8，现实剧情0.5-0.6
4. 每个副本写完用一次低温调用做校验（人设/伏笔/逻辑）
5. 维护伏笔追踪表，生成下一副本前先把清单喂给AI
