# 模块化动态提示词工作流

解决"固定提示词+连续续写导致文风死板"问题。

## 一、提示词拆两类

### 固定基底模块（100-200字，全程不变）
- 世界观锚定：核心设定、世界规则、核心冲突
- 人物锚定：主角性格、说话方式、核心动机、关键关系
- 基底调性：整体题材底色

### 动态切换模块（每章/每场景注入1-2个）
- **视角模块**：第三人称限知/全知/旁观、第一人称日记体、档案体、对话体
- **感官主导**：本章侧重触觉/听觉/视觉/空间感
- **节奏模块**：多用短句/长句、对话占比30%/70%、快节奏打斗/慢节奏过渡
- **风格修饰**：本章带冷幽默/疏离感/诗意/市井感，只微调不颠覆

## 二、参数分层

| 场景 | Temperature |
|---|---|
| 大纲/设定/校验 | 0.3-0.5（低温保逻辑） |
| 正文常规场景 | 0.6-0.7（平衡） |
| 梦境/转折/感性场景 | 0.8-0.9（鲜活） |

- frequency_penalty: 0.2-0.4（避免句式重复）
- presence_penalty: 0.1-0.2（避免话题打转）

## 三、生成粒度：场景级

不要一整章一写到底，按"地点+事件"拆成单个场景（1000-2000字）。每个场景生成前喂3条锚点：
1. 当前人物状态（情绪、身体残留、已知信息）
2. 本章核心目标（这个场景推进什么、埋什么伏笔）
3. 必须保留的细节（胎记、日记本、铁律等）

每3章做一次全局校验：人设/伏笔/时间线/感官残留逻辑。

## 四、主动打破叙事惯性

1. **视角穿插**：正文中插入日记片段、微信聊天、手稿批注、电话录音
2. **节奏错位**：紧张章后接慢节奏日常，大段环境描写后接一句短对话
3. **随机小变量**：每章加一个微小约束（出现一次白头鹎细节/主角说错一次话）

## 五、完整工作流

1. **大纲阶段**（0.4）：完整大纲、人物小传、分章梗概
2. **分章拆解**（0.6）：每章拆3-5个场景，写清目的/信息/情绪
3. **初稿生成**（0.7）：按场景逐个生成，前置锚点，动态切风格
4. **统一润色**（0.7）：整章通读，只调文风不改情节
5. **校验修正**（0.3）：检查人设/伏笔/时间线/感官逻辑
