# 番茄小说节奏与爽点设计

## 一、核心节奏原则

直白、吸睛、快节奏，信息释放密度高，拒绝拖沓注水。

- **快慢交替**：2章快节奏（冲突/打斗/反转）搭配1章慢节奏（日常/情感/设定）
- **战斗章节不连续超过2章**
- **日常过渡章节不连续超过3章**

## 二、爽点四环节闭环

完整爽点必须包含四步，缺一不可：

1. **压抑**：制造困境让主角和读者憋屈。压抑程度决定后续爽感强度，但不超过3章
2. **铺垫**：展示主角暗中准备、积蓄力量，给爽点做逻辑支撑
3. **爆发**：高光时刻，打脸/翻盘/逆袭集中释放，情绪最高点
4. **余韵**：通过围观者震惊、态度转变完成情绪闭环，放大爽感

## 三、章末断章技巧

每章结尾必须留明确悬念，让读者合上书带着焦虑感。

**有效断章：**
- 冲突一触即发
- 真相即将揭晓
- 危险悄然降临
- 反转前夕

**禁止无效断章：**
- 日常流水账结尾
- 主角吃饭睡觉就断章

## 四、移动端语言排版

- 所有描写服务剧情或人物，删无关环境描写、冗余对话、无效修饰
- 每段3-5行，避免大段文字堆砌
- 多用短句，少用长难句
- 对话单独成段，清晰区分不同人物
- 拒绝过度文艺的文笔，华丽描写会拖慢节奏

## 五、世界观轻量化

- 禁止开篇大段堆砌设定，写到哪铺到哪
- 所有设定必须服务剧情，问"这个设定能制造冲突吗"
- 先搭核心框架，历史/地理/人文细节需要时再补
- 力量体系等级清晰可量化，提前定死天花板防崩

## 六、常见雷区

**开篇：**
- 大段世界观说明像教科书
- 主角迟迟不登场
- 第一章写日常流水账
- 金手指出现太晚
- 开篇过度压抑只虐不发

**剧情：**
- 节奏注水（番茄读者弃书第一原因）
- 人设崩塌
- 强行降智推进剧情
- 巧合过多
- 反派弱智送经验
- 支线泛滥偏离主线
