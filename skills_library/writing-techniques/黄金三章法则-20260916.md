# 黄金三章法则

番茄前三章是读者留存的核心筛选器，核心原则：零铺垫、快切入、强钩子。前1000字内必须完成「冲突出现→主角登场→目标浮现→钩子落地」四件事。

## 第一章：300字定生死

- 第一句直接进入动作或对抗场景，禁止环境铺垫、背景介绍、世界观说明、回忆杀
- 场景聚焦单一现场，出场人物不超过2个（主角+直接冲突方）
- 300字内必须爆发核心冲突，同时引出主角与金手指/核心卖点
- 参考范式：
  - "刀尖抵住她喉结时，系统弹窗亮了：【检测到濒死状态，绑定'反向许愿'功能】"
  - "离婚协议签完第三分钟，前夫的助理打来电话：'沈总刚收购了您母亲的医院'"

## 第二章：700字立住人设

- 通过主角应对冲突的行为、选择、对话展现性格，禁止直白旁白介绍人设
- 初步展示主角的思维逻辑和行事风格
- 推进小半步剧情，给出第一个小型反馈，验证金手指/主角能力的作用

## 第三章：1000-1500字升级冲突

- 放大矛盾强度，给主角制造新阻碍，迫使主角做出不可逆的选择
- 结尾必须留「小反转+大疑问」双重钩子
- 明确主角的短期行动目标，锚定后续剧情方向
